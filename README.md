- **Price পরিবর্তন করুন**: কত টাকায় প্রতিটি Gmail অ্যাকাউন্ট বিক্রি হবে

#### 7️⃣ **Referral Earnings Share %** 📊 (নতুন)
রেফারেল আয়ের শতাংশ নির্ধারণ করুন:
- **Percentage সেট করুন**: যখন কোনো রেফারড ইউজার অ্যাকাউন্ট জমা দেয় এবং অনুমোদিত হয়
  - ডিফল্ট: 10% (রেফারার আয়ের 10% পায়)
  - উদাহরণ: রেফারড ইউজারের অ্যাকাউন্ট ৳5.00 → রেফারার পায় ৳0.50 (10%)
- **কাজ করে এভাবে:**
  1. ইউজার A, ইউজার B কে রেফার করে
  2. ইউজার B 5টি অ্যাকাউন্ট জমা দেয় @ ৳5.00 = ৳25.00
  3. Admin 4টি অ্যাকাউন্ট অনুমোদন করে = ৳20.00
  4. ইউজার A স্বয়ংক্রিয়ভাবে পায়: ৳20.00 × 10% = ৳2.00 রেফারেল আয়
- **Comparison Table**: বিভিন্ন শতাংশে আয়ের তুলনা
- **Strategy Tips**: 
  - 20%+ = দ্রুত বৃদ্ধি (ভাইরাল)
  - 10-15% = ভারসাম্যপূর্ণ
  - 5% = সাশ্রয়ী খরচ
- **গুরুত্বপূর্ণ**: নতুন অনুমোদনের জন্য প্রয়োগ হবে। পুরাতন ব্যালেন্স স্বয়ংক্রিয় পরিবর্তন হবে না।

## 🔗 Google Sheets ইন্টিগ্রেশন

### স্বয়ংক্রিয় সংরক্ষণ
যখন ব্যবহারকারী Gmail অ্যাকাউন্ট জমা দেয়, এটি স্বয়ংক্রিয়ভাবে আপনার Google Sheet এ সংরক্ষিত হয়।

**Google Sheet কলাম ফরম্যাট:**
```
| Column A | Column B         | Column C    | Column D         |
|----------|------------------|-------------|------------------|
| NAME     | GMAIL            | PASSWORD    | SENDER_EMAIL     |
| John Doe | johndoe@gmail.com| Pass@123!  | user@email.com   |
```

**কলাম বর্ণনা:**
- **Column A - NAME:** Gmail অ্যাকাউন্টের নাম
- **Column B - GMAIL:** Gmail ইমেইল ঠিকানা
- **Column C - PASSWORD:** Gmail অ্যাকাউন্টের পাসওয়ার্ড
- **Column D - SENDER_EMAIL:** যে ব্যবহারকারী এটি তৈরি করেছে তার ইমেইল (User ID)

### ব্যবহার করুন:
1. **ব্যবহারকারীরা Gmail তৈরি করে** → স্বয়ংক্রিয়ভাবে Google Sheet এ যায়
2. **Admin ড্যাশবোর্ড** → "Import from Google Sheets" ক্লিক করুন
3. **Spreadsheet ID পেস্ট করুন** এবং ইমপোর্ট করুন

### প্রয়োজনীয় সেটআপ:
1. Google Cloud Console এ Service Account তৈরি করুন
2. Service Account এর JSON Key ডাউনলোড করুন  
3. আপনার Google Sheet কে Service Account email এ শেয়ার করুন (Editor পারমিশন)
4. JSON Key ফাইল প্রজেক্ট ফোল্ডারে রাখুন

## 🛡️ নিরাপত্তা নোট

⚠️ **ডেভেলপমেন্ট মোডের জন্য শুধুমাত্র ব্যবহার করুন**

প্রোডাকশনের জন্য:
1. `secret_key` পরিবর্তন করুন
2. `debug=False` সেট করুন
3. একটি প্রকৃত ডাটাবেস ব্যবহার করুন (বর্তমানে মেমরিতে)
4. HTTPS সেটআপ করুন
5. প্রপার ইউজার অথেন্টিকেশন যোগ করুন

## 🐛 সমস্যা সমাধান

### পোর্ট ৫০০০ ব্যবহৃত
```bash
python -m flask run --port 5001
```

### মডিউল নোট ফাউন্ড এরর
```bash
pip install -r requirements.txt
```

### টেমপ্লেট নোট ফাউন্ড
নিশ্চিত করুন যে `templates` ফোল্ডার `app.py` এর সাথে একই ডিরেক্টরিতে আছে

## 📝 ডেটাবেস

বর্তমানে, অ্যাপ্লিকেশন Python lists এ ডেটা সংরক্ষণ করে (মেমরিতে)। অ্যাপ রিস্টার্ট করলে ডেটা হারিয়ে যাবে।

প্রোডাকশনের জন্য:
- SQLite বা PostgreSQL ব্যবহার করুন
- SQLAlchemy ORM ব্যবহার করুন
